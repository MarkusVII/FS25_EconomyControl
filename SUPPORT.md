# Support / Допомога

Use Issues to report bugs or suggest improvements. Test with a backup save and, if safe, isolate conflicting economy mods. Include game and mod versions, selected country and economic month, relevant mods, exact steps, expected/actual result, and relevant log excerpts. Remove private paths, names and account details. Remote-client and dedicated-server behavior has not been verified in real sessions. Historical indices are adapted to gameplay, not exact real-world prices.

Для повідомлення про помилку використовуйте Issues. Зробіть резервну копію збереження; за можливості ізолюйте конфліктні моди. Вкажіть версії гри та мода, країну, економічний місяць, інші моди, кроки відтворення, очікуваний та фактичний результат і відповідні рядки логу без приватних даних. Реальні клієнтські сесії та Dedicated Server ще не перевірені. Історичні індекси адаптовано до гри, а не до точних реальних цін.
